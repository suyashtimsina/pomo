# ✿ Pomo — A Little Space to Focus

A cute, minimal Pomodoro timer designed to make focused work sessions a little more enjoyable. Featuring a webcam background, soft aesthetics, and a built-in to-do list to help you stay organized.

## ✨ Features

- **Pomodoro Timer** — Focus, short break, and long break sessions.
- **Customizable Sessions** — Adjust timer durations and long-break intervals.
- **Auto-start** — Automatically begin the next session.
- **Webcam Background** — Use your camera as a live background.
- **Progress Indicator** — Track your session progress visually.
- **To-do List** — Add, complete, and delete tasks.
- **Fullscreen Mode** — Enjoy a distraction-free experience.
- **Sound Notifications** — Get notified when a session ends.
- **Persistent Settings** — Your preferences and tasks are saved locally.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser APIs (MediaDevices, Fullscreen, Web Audio)
- Local Storage

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/suyashtimsina/pomo.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pomo
   ```

3. Open `index.html` in your browser.

For the webcam feature, use `localhost` or a secure HTTPS connection and allow camera permissions.
